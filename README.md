# PetCare - Pet Shop Management System

## Project Description

PetCare is a web-based Pet Shop Management System developed to
manage pet products, categories, customers, orders, stock and
product sales through a centralized system.

## Problem Statement

Traditional pet shop management can involve manual handling of
products, stock, customer information and orders. This project
provides a computerized system to improve the management of these
activities.

## Project Objectives

- To manage pet shop products efficiently.
- To manage product categories.
- To manage customer information.
- To provide secure customer and admin authentication.
- To allow customers to browse and search products.
- To provide cart and checkout functionality.
- To manage customer orders.
- To automatically update stock after successful sales.
- To provide reports for shop management.

## How to Run the Project

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the PetShop folder to:

   C:\xampp\htdocs\

4. Create/import the `petshop` database using phpMyAdmin.
5. Import `server.sql`.
6. Import `seed.sql`.
7. Open the following URL:

   http://localhost/PetShop/
